# Reachr 🚀

Smart payment links & doorstep delivery protection for modern merchants and smart shoppers.

## Features
- **SmartPay Escrow Links**: Create custom payment links with automated escrow protection.
- **Doorstep Verification**: Safe delivery confirmations before payout release.
- **Merchant Studio**: First-time registration and management for sellers.
- **Transparent Disputes**: 4-stage fair arbitration process.
